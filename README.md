## About KeebForge

KeebForge is a mechanical keyboard and peripherals store and workshop based
in Jammu, India.

We provide:

- Mechanical keyboards and peripherals
- Custom keyboard builds
- Keyboard and mouse modifications
- Keyboard repairs and troubleshooting
- Switch and stabilizer tuning
- Soldering and desoldering
- Hot-swap and PCB repairs
- Keyboard and mouse services
- Order and shipment tracking

The KeebForge platform brings the store, workshop services, checkout,
payments, shipping, and customer order tracking together in one place.

## Architecture

KeebForge is built as a modern full-stack web platform using Next.js and
Vercel, with PostgreSQL for data and integrated services for authentication,
payments, shipping, media, email, and realtime order tracking.
